## Overview

Wordy is a sleek, modern web dictionary application built with HTML, CSS, and JavaScript, powered by the [Dictionary API](https://dictionaryapi.dev/). It allows users to search for word definitions, pronunciations, parts of speech and audio examples with a clean, user-friendly interface.

## Features

- Search for any English word – Get instant definitions

- Audio Pronunciation – Listen to how the word is spoken

- Definitions – See different meanings and parts of speech

- Fast & Responsive – Works on all devices

- Modern UI – Clean, minimal, and visually appealing

## Local Setup

### Requirements

- A modern web browser
- Intenet access

### Installation

1. Clone the repository:

	```bash
	git clone git@github.com:Victor-Mufasa/Wordy.git
	```

2. Navigate into the Wordy folder/directory:

	```bash
	cd Wordy/
	```

3. Right click the index.html file and open it in the browser.

### Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Dictionary API
